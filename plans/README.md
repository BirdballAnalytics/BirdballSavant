# Development plans and weekly feedback

Upload a PDF here (**Add file → Upload files**) with the player's name at the start of the file name:

* `Toomey - Weekly feedback 2026-10-19.pdf`
* `Jack Toomey - Fall development plan.pdf`
* `#6 - Hitting plan.pdf` (jersey number works too)
* or put it in a folder named for him: `Toomey/anything.pdf`

* A date in the name (2026-10-19 or 10.19.26) is shown as the week. Without one, the upload date is used.
* "feedback" or "weekly" in the name marks it as **Weekly feedback**; anything else is a **Development plan**.
* Two players with the same last name (Ryan): use the full name, `Jack Ryan - ...`.

It shows up on the player's phone (Profile → Development plans) a few minutes after you upload,
locked with his personal plan code. Coaches see every player's code on their dashboard
(Profile → your name → staff password). To take one down, delete the file here.

Files whose name doesn't match a player are listed in red on the coach dashboard.
